# JavaScriptfundamentos03

Continuação dos estudos de JavaScript com foco em funções, métodos de array, obejtos, JSON e introdução á Programação Orientada a Objetos.

## Objetos 

Ao final deste projeto, o aluno deverá ser caçpaz de:

- Criar e utilizar funções;
- Trabalhar com parâmetros, argumentos e retornos;
- Utilizar Arrow Functions;
- Criar e manipular objetos;
- Ttrabalhar com array de objetos;
- Entender o uso de `this`;
- Converter objetos para JSON e JSON para objetos;
- Criar classe;
- Utilizar `construtor`;
- Instanciar objetos com `new`;
- Criar atributos e métodos;
- Compreender os conceitos iniciais de encapsulamento, herança e polimorfismo;

### Como executar 

- Abra o terminal na pasta e execute:

```bash
   node nome-do-arquivo.js
```

### Funções

Funções permitem organizar e reutilizar códigos.

```javascript
   function saudacao(){
    console.log("Olá");
   ```
